🏛️ HTMS — Cài Đặt Hội Thánh Mới

Hệ Thống Quản Lý Hội Thánh · Church Management System

📋 Yêu Cầu Hệ Thống

  • Ubuntu 22.04 + CyberPanel (OpenLiteSpeed)
  • PHP 8.3 (CLI: /usr/local/lsws/lsphp83/bin/php)
  • MySQL 8.0+
  • Composer 2.x
  • Git

1 Tạo Website Mới Trong CyberPanel

CyberPanel → Websites → Create Website
  1. Domain Name: quanly.ten-mien.com
  2. PHP: chọn PHP 8.3
  3. Tích: Create Mail Domain (tuỳ chọn)
  4. Nhấn Create Website
💡 CyberPanel sẽ tạo thư mục /home/[user]/public_html và tự cấu hình virtual host. Không cần IP mới — dùng chung IP server.

2 Tạo Database MySQL

CyberPanel → Databases → Create Database
  1. Database Name: htms_thanhtuyen
  2. Database User: htms_ttuyen_user
  3. Password: (tạo mật khẩu mạnh)
  4. Ghi lại 3 thông tin này — dùng ở Bước 4

3 SSH Vào Server

ssh [user]@[server-ip]
# Di chuyển vào thư mục website vừa tạo
cd ~/public_html
💡 Nếu thư mục public_html đã có file, xoá hết trước:
rm -rf ~/public_html/*

4 Chạy Script Cài Đặt Tự Động

Chạy 1 lệnh dưới đây — script sẽ clone code, hướng dẫn cấu hình .env, và cài đặt tất cả:

# Cách 1: Chạy trực tiếp từ GitHub (khuyến nghị)
bash <(curl -s https://raw.githubusercontent.com/haiyenpa25/HTMS/main/deploy/deploy-new-church.sh)

# Cách 2: Nếu đã clone repo
bash deploy/deploy-new-church.sh
⏳ Quá trình cài đặt khoảng 3-5 phút. Script sẽ dừng lại để bạn điền thông tin .env trước khi tiếp tục.

5 Các Biến .env Quan Trọng

Script sẽ tự copy file mẫu. Bạn cần điền các giá trị sau:

BiếnGiá trị ví dụGhi chú
APP_URL bắt buộc https://quanly.httlthanhtuyen.com URL đầy đủ với https://
DB_DATABASE bắt buộc htms_thanhtuyen Tên DB đã tạo ở Bước 2
DB_USERNAME bắt buộc htms_ttuyen_user User DB đã tạo ở Bước 2
DB_PASSWORD bắt buộc Mat_khau_manh! Password DB
CHURCH_NAME bắt buộc Hội Thánh Tin Lành Thanh Tuyền Tên hiển thị trên hệ thống
SYSTEM_DOMAIN bắt buộc httlthanhtuyen.com Tạo email: superadmin@[domain]
SUPERADMIN_PASSWORD bắt buộc Abc.1234@HoiThanh Mật khẩu tài khoản quản trị đầu tiên
CHURCH_ADDRESS tuỳ chọn 123 Đường ABC, Quận 1, TP.HCM Địa chỉ Hội Thánh
CHURCH_PHONE tuỳ chọn 0901 234 567 Điện thoại liên hệ
CHURCH_EMAIL tuỳ chọn contact@httlthanhtuyen.com Email chính thức

6 Các Bước Tiếp Theo Sau Cài Đặt

Sau khi script chạy xong, login bằng tài khoản SuperAdmin để:

  1. Đăng nhập: superadmin@[SYSTEM_DOMAIN] / mật khẩu trong .env
  2. Vào Admin → Hội Thánh để thêm logo, cập nhật thông tin
  3. Vào Admin → Người Dùng để tạo tài khoản Mục Sư / Trưởng Ban
  4. Vào Admin → Tính Năng & Quyền để phân quyền cho từng ban ngành

Lệnh tùy chọn thêm (chạy sau khi đã login kiểm tra):

# Tạo tài khoản đại diện mặc định cho các ban ngành (Trưởng Ban, Thư Ký,...)
/usr/local/lsws/lsphp83/bin/php artisan db:seed --class=OrgStructureSeeder

🔄 Cập Nhật Code Khi Có Version Mới

Chạy lệnh này trên server để cập nhật hệ thống:

cd ~/public_html \
  && mkdir -p ~/bin && ln -sf /usr/local/lsws/lsphp83/bin/php ~/bin/php && export PATH="$HOME/bin:$PATH" \
  && git checkout -- index/ \
  && git pull origin main \
  && composer install --no-dev --optimize-autoloader --ignore-platform-reqs \
  && php artisan migrate --force \
  && php artisan config:cache \
  && php artisan route:cache \
  && php artisan view:cache
