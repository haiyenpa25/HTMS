Hệ Thống Quản Lý Hội Thánh · Đã cập nhật từ thực tế triển khai

📋 Yêu Cầu Hệ Thống

  • Ubuntu 22.04 + CyberPanel (OpenLiteSpeed)
  • PHP 8.3 — CLI path: /usr/local/lsws/lsphp83/bin/php
  • Composer 2.x (thường ở /usr/local/bin/composer)
  • MariaDB/MySQL 8+, Git
⚠️ Lưu ý: Trên CyberPanel, php không có trong PATH mặc định. Luôn dùng đường dẫn đầy đủ hoặc thiết lập alias trước.

1 Tạo Website Trong CyberPanel

  1. Websites → Create Website
  2. Domain: quanly.ten-mien.com
  3. PHP: chọn PHP 8.3 (quan trọng!)
  4. Nhấn Create Website
💡 CyberPanel sẽ tự tạo virtual host và trỏ document root vào public_html/public (đúng cho Laravel). Không cần IP mới — dùng chung IP server.

2 Tạo Database MySQL

  1. Databases → Create Database
  2. Điền Database Name, Username, Password
  3. Ghi lại cả 3 thông tin này — dùng ở Bước 5
🔴 Lỗi thường gặp: CyberPanel tạo DB và User nhưng chưa cấp quyền. Nếu gặp "Access denied" khi migrate → xem Bước Xử Lý Lỗi bên dưới.

3 SSH + Fix PHP Path (Làm Trước Tiên)

CyberPanel không có php trong PATH. Thiết lập trước khi làm bất cứ điều gì:

ssh [user]@[server-ip]
cd ~/public_html

# Thiết lập PHP path — LUÔN chạy dòng này trước
mkdir -p ~/bin && ln -sf /usr/local/lsws/lsphp83/bin/php ~/bin/php
export PATH="$HOME/bin:/usr/local/lsws/lsphp83/bin:$PATH"

# Kiểm tra
php -v   # Phải ra PHP 8.3

4 Clone Code + Chạy Script

# Xoá file mặc định CyberPanel (nếu có)
rm -rf ~/public_html/* ~/public_html/.*  2>/dev/null || true

# Chạy script cài đặt tự động
bash <(curl -s https://raw.githubusercontent.com/haiyenpa25/HTMS/main/deploy/deploy-new-church.sh)
⏳ Script sẽ dừng ở Bước 2/7 để bạn điền .env. Sau đó nhấn Enter để tiếp tục.

6 Sau Khi Script Hoàn Tất — Fix Quyền & Reload

# Fix quyền thư mục
chmod -R 755 ~/public_html/storage ~/public_html/bootstrap/cache
chown -R $(whoami):$(whoami) ~/public_html/

# Tạo storage symlink
php ~/public_html/artisan storage:link

# Reload OpenLiteSpeed để nhận config mới
sudo systemctl reload lsws
# Hoặc nếu không dùng được sudo:
sudo /usr/local/lsws/bin/lswsctrl restart
💡 Bước reload OpenLiteSpeed thường bị bỏ qua — đây là nguyên nhân phổ biến khiến website không lên dù đã cài xong.

7 Cấu Hình DNS + SSL

  1. Thêm A record: quanly.ten-mien.com → [IP server]
  2. Đợi DNS propagate (~5-30 phút)
  3. CyberPanel → SSL → Issue SSL cho domain này

⚠️ Xử Lý Lỗi Thường Gặp

🔴 "No such file or directory: php" khi chạy composer

mkdir -p ~/bin && ln -sf /usr/local/lsws/lsphp83/bin/php ~/bin/php
export PATH="$HOME/bin:/usr/local/lsws/lsphp83/bin:$PATH"
php /usr/local/bin/composer install --no-dev --optimize-autoloader --ignore-platform-reqs

🔴 "Access denied for user" khi migrate

User DB chưa có quyền. Chạy lệnh sau (thay bằng thông tin thật):

mysql -u root -p$(cat /etc/cyberpanel/mysqlPassword)

-- Trong MySQL prompt (thay đúng tên DB, user, password từ .env):
GRANT ALL PRIVILEGES ON `ten_database`.* TO 'ten_user'@'localhost' IDENTIFIED BY 'mat_khau_that_trong_env';
FLUSH PRIVILEGES;
EXIT;
❗ Quan trọng: Điền đúng password từ .env DB_PASSWORD vào IDENTIFIED BY — không được điền password khác, sẽ bị mismatch.

🔴 Website không load dù đã cài xong

# Xem log lỗi
tail -50 ~/logs/[domain].error_log

# Reload OpenLiteSpeed
sudo systemctl reload lsws

# Kiểm tra .htaccess
cat ~/public_html/public/.htaccess
